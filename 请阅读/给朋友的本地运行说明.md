# 本地运行说明（给新手朋友）

这个项目不是单纯前端页面，它也有后台、数据库和管理员初始化。想跑起来，按下面顺序做就可以。

## 1）先装东西

先确认你电脑装好了：

- Node.js 22+
- pnpm

在项目根目录跑：

```bash
pnpm install --frozen-lockfile
```

如果还没装 pnpm：

```bash
npm install -g pnpm
```

如果输出里出现 `vinext: command not found`，说明 `node_modules` 还没装好，先执行上面的 `pnpm install --frozen-lockfile`，再继续。

另外，这个项目要求 Node.js 22.13.0 以上。你当前机器如果是 `v22.12.0`，要升级到 22.13+，否则会有 engine warning。

## 2）准备环境变量

在项目根目录创建两个文件：

- `.env`
- `.dev.vars`

内容写成这样：

```env
ADMIN_SETUP_TOKEN=随便写一个随机字符串
ADMIN_EMAIL=admin@example.invalid
```

例如：

```env
ADMIN_SETUP_TOKEN=abc123xyz
ADMIN_EMAIL=admin@example.invalid
```

这里的 token 以后会用来创建第一个管理员账号；它不需要是真实邮箱。

## 3）初始化本地数据库

先删掉旧的本地数据库缓存：

```bash
rm -rf .wrangler
```

然后按顺序执行：

```bash
pnpm exec wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0000_watery_blockbuster.sql
pnpm exec wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0001_business_guards.sql
pnpm exec wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0002_milky_bug.sql
pnpm exec wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/0003_media_guards.sql
```

这些命令会创建本地数据库表。

## 4）启动网站

```bash
pnpm dev
```

然后打开浏览器：

```text
http://localhost:3000
```

## 5）创建第一个管理员

不是直接登录，而是先去：

```text
http://localhost:3000/setup#key=你的TOKEN
```

比如：

```text
http://localhost:3000/setup#key=abc123xyz
```

在页面里填：

- 用户名
- 邮箱：要和 `.env` 里的 `ADMIN_EMAIL` 一样
- 密码
- 确认密码
- token：和 `.env` 里的 `ADMIN_SETUP_TOKEN` 一样

创建成功后，就可以登录：

```text
http://localhost:3000/login
```

之后管理后台在：

```text
http://localhost:3000/admin
```

## 6）如果网站报错，怎么 debug

最常见的情况：

### 情况 1：页面白屏 / 500

先看终端输出。跑 `pnpm dev` 之后，终端会直接报错。最常见的是：

- 路径问题
- 环境变量没配好
- 数据库还没建表

### 情况 2：跑到 `/setup` 还是报 “管理员已初始化，或初始化凭证无效”

这通常说明两件事：

- 之前已经创建过管理员
- 或 token / email 不一致

解决办法：

```bash
rm -rf .wrangler
```

然后重新跑数据库初始化命令，再重启 `pnpm dev`。

### 情况 3：页面能开，但接口报错

检查本地数据库是否真的建好：

```bash
pnpm exec wrangler d1 execute DB --local --config wrangler.local.json --command "SELECT * FROM settings;"
```

如果表缺失，说明数据库初始化没跑完。

## 7）这是什么项目

这是一个有后台、数据库、登录、积分、发帖、评论和管理员页面的论坛项目。它不是单纯静态网页，所以不能只打开 HTML 文件就能用。必须有：

- Node 运行环境
- 本地数据库
- 环境变量
- 本地开发服务器

## 8）最重要的一句话

先跑 `pnpm install`，再配 `.env` 和 `.dev.vars`，再建本地数据库，最后用 `/setup` 创建管理员。这样最稳。

如果遇到错误，先看终端报错，再检查：

- `.env` 是否正确
- `.dev.vars` 是否一致
- `.wrangler` 是否已重建
- `/setup` 里 token 和 email 是否和 `.env` 完全一致

这样就能快速定位问题。
