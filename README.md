# 同好交流论坛

具备真实账号、数据库和私有媒体存储的同好社区。正式环境不会导入本地测试账号或测试帖子。

## 首次使用

1. 打开交付的管理员初始化链接，填写指定管理员邮箱、用户名和自行设置的密码。
2. 初始化凭证只用于建立首个管理员，成功后自动失效。
3. 管理员可以进入论坛和 `/admin`，配置积分规则、准入题目、上传限制及封禁方式。
4. 普通用户完成准入答题后注册，初始积分为 0。

Sites 访问范围与论坛账号是两层独立控制。初次发布为仅站点所有者可访问；需要将外层入口开放后，其他同好才能进入答题和注册。论坛内容始终由论坛登录、封禁与积分权限保护。

## 已实现

- 30 分钟、一次性、HttpOnly 答题状态；随机抽题、题库管理、必答校验。
- 用户名/邮箱唯一约束、密码安全哈希、登录与退出、服务器端会话。
- 发文区、发图区、视频区、水区，搜索、最新/热门信息流、详情、点赞、评论。
- 可排序文字/图片/视频内容块、媒体说明、文字选区锁定、逐块公开/锁定切换。
- 私有 R2 媒体、8 MiB 分段上传、进度、视频自动封面、受控 Range 播放请求。
- 签到、积分流水、每日奖励上限、重复内容识别、原子奖励与幂等回滚。
- 个人主页、头像、积分及权限成长提示。
- 管理员用户/帖子/评论管理、临时/永久封禁、积分设置、题库设置、操作日志。
- 普通接口白名单返回用户资料；锁定正文及媒体地址在服务端过滤。
- 桌面与手机布局、手机导航、空状态、错误提示、删除确认。

## 统一的业务默认

| 规则                       | 实现                                                   |
| -------------------------- | ------------------------------------------------------ |
| 发帖门槛                   | 10 分                                                  |
| 评论门槛                   | 30 分，采用最终验收场景 F                              |
| 待解锁门槛                 | 30 分，不消耗积分；作者及管理员豁免                    |
| 含锁定块的发文最低公开内容 | 50 个有效字符，采用最后的默认设置                      |
| 图区最低公开图片           | 1 张，且须有公开简介                                   |
| 评论每日奖励               | 最多 6 分，剩余额度不足时截断奖励                      |
| 短评论 2 分 + 长评论 5 分  | 同一天合计最多 6 分；分别验收完整单条奖励              |
| 删除内容                   | 扣回实际曾入账积分；不恢复当天奖励额度                 |
| 当前积分                   | 完整记账允许回滚后出现负数；权限按非负有效积分展示进度 |
| 关闭锁定功能               | 禁止新增锁定块，已有锁定内容保持保护                   |
| 封禁方式                   | 默认允许受限登录查看原因；可改为禁止登录               |
| 签到日期                   | 服务器按 Asia/Shanghai 计算                            |

## 数据与安全

D1 存储业务数据，R2 存储文件。所有表由 Drizzle 迁移维护；运行时只初始化默认设置和默认题目。密码采用随机盐 PBKDF2-SHA256（100,000 次）；会话标识随机生成，只保存其 SHA-256 摘要。生产 Cookie 为 Secure、HttpOnly、SameSite=Strict。

帖子、评论与积分变更在 D1 `batch` 事务内提交。数据库触发器维护余额、流水余额快照、内容奖励和评论数，并在写入时复查积分及封禁。积分来源和签到日期有唯一约束。编辑和删除不抹去历史内容指纹。媒体绑定不能跨帖子重写。

私密媒体没有公开存储地址。每次 GET、HEAD、Range 请求都验证最新会话、封禁、帖子状态、积分、作者身份；响应 `private, no-store`。服务端不会把正确答案、密码或其他用户邮箱放入普通 API 响应。

## 媒体边界

图片支持 JPEG、PNG、GIF、WEBP；服务端校验文件头、尺寸和容器结束结构。视频支持 MP4/MOV 的 H.264、VP9、AV1 兼容轨道，以及 WEBM 的 VP8/VP9/AV1 轨道。服务端解析容器和轨道，拒绝只有伪造文件头的文件。浏览器在上传前验证可读取画面，并自动生成封面。

未提供视频转码服务。某些 MOV 使用 ProRes、HEVC 等编码，需要先导出为 H.264 MP4；不能把“支持 MOV 文件扩展名”理解为支持全部 MOV 编码。播放能力仍受终端浏览器的解码器支持限制。上传上限可调整，分段传输避免将完整大视频放入 Worker 内存。

## 开发和复验

保留原始 pnpm 锁文件。设置 `.dev.vars` 与 `.env` 中的 `ADMIN_SETUP_TOKEN` 和 `ADMIN_EMAIL`，参考 `.env.example`。不要提交真实凭证。

- `pnpm dev`：开发预览。
- `pnpm build`：生成 Cloudflare Worker 与浏览器资源。
- `pnpm db:generate`：生成增量迁移。
- `wrangler d1 execute DB --local --config wrangler.local.json --file drizzle/<迁移>.sql`：按顺序初始化本地数据库。
- `python tests/acceptance.py`：核心业务验收。
- `python tests/security.py`：并发、格式、过期、唯一性、分页、大图上传验收。
- `python tests/media.py`：正常视频与伪造 WEBM 反例验收。

测试脚本仅连接 `http://localhost:3000`，使用 `.wrangler` 中的本地持久化数据库，不连接线上。连续五天签到通过四个历史服务端日期的测试记录，加一次当前日期的真实接口签到完成模拟。真实视频测试样本来自 MDN 的公开 CC0 示例，只保存在忽略的测试目录。
